# Plant Care Scheduler

A simple console-based Python application to manage plants
and schedule their care activities.

## Features

- Add and view plants
- Search plants
- Schedule watering
- Schedule fertilizing
- Schedule pruning and other activities
- View care schedules
- Mark activities as completed
- View due and overdue care activities
- Generate plant care reports
- Store records using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Lists and Dictionaries
- DateTime

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd Plant_Care_Scheduler
```

Run the application:

```bash
python main.py
```

## Data Storage

Plant details are stored in:

`data/plants.json`

Care activities are stored in:

`data/care_records.json`
